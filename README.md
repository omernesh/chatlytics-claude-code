# Chatlytics Plugin for Claude Code

Give your Claude Code agent WhatsApp messaging superpowers.

## Install

```bash
# From the plugin directory
claude plugin install /path/to/chatlytics-plugin
```

## Configure

Set these environment variables in your Claude Code settings:

```
CHATLYTICS_API_URL=https://app.chatlytics.ai
CHATLYTICS_API_KEY=your-api-key
CHATLYTICS_SESSION=your-session-id
```

## What You Get

- **6 MCP tools** for WhatsApp messaging (send, read, search, directory, actions, health)
- **Skill** that teaches Claude Code when and how to use WhatsApp
- Zero configuration beyond the 3 env vars

## Usage

Just ask Claude Code:
- "Send a WhatsApp message to Omer saying hello"
- "Read my recent WhatsApp messages"
- "Search for the Team Chat group"
- "Check if WhatsApp is connected"
